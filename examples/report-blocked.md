# 예시: 차단이 나온 보고서

가상의 대상(`sample-skill`)을 점검한 결과입니다. 회사명과 값은 모두 가상입니다.

## 공개 점검 결과: sample-skill

판정: 차단 3건 / 경고 1건 → **공개하지 마세요**

### 차단
| 구분 | 위치 | 내용(가린 미리보기) | 조치 안내 |
|---|---|---|---|
| 사용자 사전 | `SKILL.md:14` | `가**전자` | 가상 회사명으로 바꾸거나 문장을 일반화하세요 |
| API 키(sk- 형태) | `references/api.md:3` | `sk-ab…(32자)` | 파일에서 지우고 **키를 폐기**하세요 |
| 커밋 작성자 이메일 | git 이력 | `…@company.example` | 개인 주소로 새 저장소를 만들어 올리는 방법을 검토하세요 |

### 경고 (사람이 판단)
| 구분 | 위치 | 내용(가린 미리보기) | 조치 안내 |
|---|---|---|---|
| 로컬 경로 | `README.md:22` | `C:\Users\k**\…` | 예시 경로(`C:\Users\<이름>\`)로 바꾸세요 |

### 구조 점검
| 항목 | 결과 |
|---|---|
| `name`이 폴더 이름과 일치 | 통과 |
| LICENSE | **없음** |
| README 설치 방법 | 통과 |

### 확인하지 못한 것
- 이미지·PDF 속 글자
- 규칙과 사전에 없는 기밀

### 다음에 할 일
1. 키를 폐기하고 파일에서 지우세요(이력에 남아 있으면 이미 유출된 것으로 봅니다).
2. 회사명이 든 문장을 일반화하세요.
3. LICENSE를 추가하고 다시 점검하세요.
