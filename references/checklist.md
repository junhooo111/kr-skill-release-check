# 공개 전 점검표

점검 후 항목마다 통과 / 실패 / 해당 없음으로 표시한다.

## 스킬 구조

- [ ] `SKILL.md`가 있고 맨 위가 `---`로 시작하는 프런트매터다
- [ ] `name`이 소문자·숫자·하이픈이고 폴더 이름과 같다
- [ ] `description`이 "언제 쓰는지"를 구체적으로 말한다 (사용자가 하는 말의 예시 포함)
- [ ] 프런트매터에 쓰이지 않는 필드가 없다
- [ ] 본문이 지시문 형태이고, 한 스킬이 하나의 일만 한다
- [ ] 참조 파일(`references/`, `examples/`)의 경로가 본문과 맞는다

## 문서와 라이선스

- [ ] `LICENSE` 파일이 있다 (없으면 기본적으로 남이 쓸 수 없다)
- [ ] 다른 저장소에서 가져온 내용이 있으면 출처와 라이선스를 적었다
- [ ] `README`에 무엇을 하는지, 설치 방법, 사용 예가 있다
- [ ] 설치 명령이 실제로 동작하는지 한 번 확인했다
- [ ] 한계(못 하는 것)를 적었다

## 기밀

- [ ] 규칙 점검에서 차단이 0건이다
- [ ] 사용자 사전 점검에서 0건이다
- [ ] 사용자 사전 파일이 `.gitignore`에 들어 있거나 저장소 밖에 있다
- [ ] git 이력의 작성자 이메일이 개인 주소다 (회사 주소 아님)
- [ ] 이력에 남은 비밀 값이 없다
- [ ] 예시에 쓴 회사·고객·인물 이름이 가상이다
- [ ] 이미지와 PDF 속 글자를 직접 눈으로 확인했다

## 내용의 성격

- [ ] 회사 내부 절차나 문서를 그대로 옮긴 부분이 없다
- [ ] 이 스킬이 다루는 주제로 공개해도 회사 규정에 문제가 없다 (확신이 없으면 회사에 확인)

## 공개 후

- [ ] GitHub 토픽(`claude-skills` 등)을 추가했다
- [ ] 다른 사람이 설치해 보고 동작하는지 확인했다
